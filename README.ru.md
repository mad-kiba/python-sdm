# Python-SDM
Species Distribution Modelling (SDM) library for Python.

Библиотека для моделирования распространения видов (SDM) для Python.

Суть SDM - поиск закономерностей между местами наблюдения вида и условиями окружающей среды в этих местах, с последующим построением непрерывной карты вероятности присутствия на интересующей территории (для настоящего, будущего и прошлого, в том числе помесячно).

Доступна онлайн, с большим набором предикторов, уже приведённых к одному пространственному разрешению, - можно запустить модель для любого из уже поддерживаемых видов без локальной установки:
- Демо: https://wingeds.world/sdm (русская версия) / https://wingeds.world/en/sdm (английская версия)
- Документация: https://wingeds.world/sdmdoc (русская версия) / https://wingeds.world/en/sdmdoc (английская версия)

Онлайн поддерживаются птицы, млекопитающие, рептилии, насекомые и растения.

Подробнее про алгоритм SDM: https://habr.com/ru/articles/983756/

## Методологические примечания

Для читателей, знакомых с литературой по SDM/ENM, стоит явно отметить несколько решений, принятых в реализации:

- **Доступность территории (параметр «M» в диаграмме BAM, Soberón & Peterson, 2005; Barve et al., 2011).** Вместо плоского евклидова буфера вокруг известных точек наблюдения доступную территорию можно считать как cost-distance (поверхность трения) методом Fast Marching, где уклон рельефа, пределы по высоте и водоёмы работают как барьеры настраиваемой силы. Доступно несколько функций затухания от буфера наблюдений к нулю (buffer, linear, sigmoid, exponential, inverse-quadratic, Gaussian).
- **Поправка на смещение выборки наблюдений.** Фоновые/псевдо-отсутствующие точки могут выбираться с вероятностью, пропорциональной сглаженной суммарной плотности всех наблюдений GBIF того же таксономического класса в регионе — по идее target-group background из Phillips et al. (2009), а не чисто случайно.
- **Оценка качества.** Помимо ROC AUC, TSS и каппы Коэна выводится continuous Boyce index (Hirzel et al., 2006) — метрика, не требующая данных о подтверждённом отсутствии вида.
- **Диагностика ниши по каждому предиктору.** Для каждого слоя условий среды распределение значений в точках наблюдения сравнивается с распределением по всему доступному фону через индекс Шёнера (Schoener, 1968; см. также Warren et al., 2008), вместе со сводными статистиками (медиана, перцентили, стандартизованная разница медиан).
- **Модели.** Поддерживаются Random Forest и XGBoost (scikit-learn / xgboost); GLM (логистическая регрессия с линейными и квадратичными признаками, сила L2-регуляризации подбирается кросс-валидацией по ROC AUC — квадратичный член нужен, чтобы описать унимодальный, а не только монотонный отклик вида на предиктор, см. ter Braak & Looman, 1986); и MaxEnt, адаптированный из модельного ядра [elapid](https://github.com/earth-chris/elapid) (linear/hinge/threshold/product-признаки, логистическая регрессия с L1-регуляризацией, калибровка выхода raw/logistic/cloglog) без геопространственной обвязки для работы с растрами/векторами — она самой модели не нужна, а наш пайплайн делает это сам. Прогноз на будущее и прошлое сейчас поддержан только для Random Forest и XGBoost.

## Данные

- Источники наблюдательных данных: GBIF.org, iNaturalist.org, eBird.org, wingeds.world, plantarium.su и др.
- Условия среды: WorldClim (температура, осадки), SRTM (рельеф, высоты), OpenStreetMap (речные и дорожные сети) и др.

## Установка и запуск локальной версии

**Для запуска Python-SDM локально нужно:**

1. Скачать библиотеку в отдельную папку, например, `python_sdm`.

2. Установить Python:
```
yum install python3 python3-pip libxcb mesa-libGL # CentOS, RHEL
# или
apt install python3 python3-pip libxcb1 libgl1 # Ubuntu, Debian
```
3. Установить дополнительные библиотеки:
```
pip install pandas numpy scipy matplotlib scikit-learn xgboost opencv-python rasterio contextily pyproj Pillow affine joblib
```

**Технически библиотека готова к запуску. Дальше собираем исходные данные: слои-предикторы и наблюдательные данные:**

4. Создать папку `python_sdm\input_predictors` для предикторов. В ней может быть до пяти подпапок:
- `python_sdm\input_predictors\static` - предикторы в этой папке считаются статическими, неизменными по времени. Соответственно, модель может их использовать и для текущего времени, и для будущего (например, высота над уровнем моря - WorldClim height);
- `python_sdm\input_predictors\dynamic_current` - предикторы в этой папке считаются динамическими (например, WorldClim BIOxx). Если вы моделируете будущее, файлы с аналогичным названием должны лежать в следующей папке:
- `python_sdm\input_predictors\dynamic_predictable` - в этой папке лежат предикторы будущего (например, WorldClim BIOxx SSP370). Структура: подпапка на каждый период (например, `2041-2060`), а внутри неё - подпапка на каждый сценарий (например, `ssp370`), то есть `dynamic_predictable\2041-2060\ssp370\`;
- `python_sdm\input_predictors\dynamic_past` - в этой папке лежат предикторы прошлого (например, CHELSA TraCE21k). Структура проще: подпапка на каждый период без сценариев (например, `dynamic_past\02-180\`), и отдельная обязательная подпапка `dynamic_past\learning\` с предикторами "настоящего" в том же формате, что и остальные периоды прошлого - на них обучается отдельная модель для прогноза прошлого;
- `python_sdm\input_predictors\dynamic_monthly` - если включён помесячный прогноз (`MODEL_SEASON: 1`), сюда кладутся предикторы по месяцам: подпапка на каждый месяц (`1` … `12`).

Предикторы должны быть в формате GeoTIFF. Если в GeoTIFF несколько слоёв, используется только первый из них.

Для минимального запуска можно скачать `WorldClim elevation` (https://www.worldclim.org/data/worldclim21.html - масштаб `30 seconds`) и распаковать в папку `python_sdm\input_predictors\static`, а `Bioclimatic variables` скачать и распаковать в папку `python_sdm\input_predictors\dynamic_current`.

5. Скопировать содержимое папки `python_sdm\examples` (папку `data` и файл `example_minimal.py`) в корень папки `python_sdm` (туда же, где лежат папки `sdm` и `input_predictors`).

6. В этой папке выполнить команду:
```
python example_minimal.py
```
В результате будет запущена SDM для сапсана (*Falco peregrinus*) на территории Алтая.

7. В папку `python_sdm\data` можно загрузить наблюдательные данные по любому интересующему виду - их можно взять на GBIF.org. Несколько минимальных примеров уже лежит в папке `examples\data`.
