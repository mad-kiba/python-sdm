# Документация Python-SDM

Python-SDM — библиотека на Python для моделирования распространения видов (Species Distribution Modelling, SDM / Ecological Niche Modelling, ENM): по точкам наблюдения вида и слоям условий среды она строит непрерывную карту вероятности присутствия для текущего, будущего и прошлого временных периодов, в том числе помесячно.

Эта документация описывает **сам модуль `sdm`** как самостоятельную Python-библиотеку: как её установить, какие входные данные ей нужны, как вызвать её API и что она возвращает. У автора библиотеки есть собственный онлайн-сервис (веб-интерфейс + HTTP-сервер над этим же модулем, см. https://wingeds.world/sdm), но это лишь один из возможных вариантов использования модуля — сам модуль не зависит от какого-либо конкретного фронтенда или сервера и работает изолированно: его можно вызывать напрямую из обычного Python-скрипта, как показано в [usage.md](usage.md).

## Общая логика

1. Модуль принимает точки наблюдения вида (CSV, обычно экспортированный с GBIF.org) и набор растровых слоёв-предикторов условий среды (GeoTIFF).
2. Генерирует фоновые точки/точки псевдо-отсутствия с учётом доступной территории ("M" в диаграмме BAM, Soberón & Peterson, 2005) и, опционально, поправки на смещение выборки наблюдений (target-group background, Phillips et al., 2009).
3. Обучает одну из поддерживаемых моделей (Random Forest, XGBoost, GLM или MaxEnt) и считает метрики качества (ROC AUC, TSS, каппа Коэна, continuous Boyce index).
4. Строит карту пригодности территории (GeoTIFF + JPEG) для текущего периода и, если включено, для будущего, прошлого и по месяцам.
