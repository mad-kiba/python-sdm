# Профили условий: статистики гистограмм

Статистики каждого слоя лежат в `histogram_stats` файла `{id}.json` и в `{id}_gistos.js`. Все значения приведены в исходных единицах слоя (после `inverse_scale`) и округлены до 4 значащих цифр. Отсутствующее значение записывается как `null`.

Описан формат `stats_version: 2`. В моделях без этого поля D считался неверно, поэтому показывать его и стрелки направления для них нельзя.

## Формат

```json
"CHELSA_fcf_1981-2010_V.2.1": {
  "unit": "раз/год",
  "kind": "continuous",
  "n_obs": 422,
  "n_region": 864000,
  "stats_version": 2,
  "bins": 41,
  "obs": { "mean": 0, "median": 0, "min": 0, "max": 0, "p5": 0, "p10": 0, "p90": 0, "p95": 0,
           "width_p10_p90": 0, "std": 0, "skewness": 0, "kurtosis": 0 },
  "region": { },
  "metrics": { "schoener_d": 0.71, "rel_width": 0.58, "std_diff": 0.65, "direction": "higher", "obs_in_region_pct": 92 }
}
```

Числа в примере условные, а `region` содержит те же поля, что и `obs`. Если у слоя не удалось посчитать статистики, вместо этой структуры будет `null`.

У категориальных слоёв (`kind: "categorical"`, признак задан в `predictors_info.py`) `obs` и `region` содержат только `share`, долю точек со значением 1 в диапазоне от 0 до 1. В `metrics` у них только `schoener_d`, а `bins` равен 2.

## Индекс Шёнера (`schoener_d`)

D = 1 − ½·Σ|pᵢ − qᵢ|, где pᵢ и qᵢ — доли точек присутствия и точек региона в интервале i (сумма долей равна 1).

- **Значения:** от 0 до 1, отрицательных не бывает. 1 означает, что условия в местах наблюдений распределены так же, как по региону, то есть фактор вид не ограничивает. 0 означает, что распределения не пересекаются.
- **Интервалы:** равные, на общем диапазоне вида и региона, поэтому точки вне диапазона региона не теряются. Их число равно min(50, max(10, ⌊2·√n_obs⌋)) и записывается в `bins`.
- **Мало данных:** при `n_obs` < 10 значение равно `null`.

## Относительная ширина (`rel_width`)

`rel_width` — это отношение ширины P10–P90 у вида к ширине P10–P90 в регионе. Обе ширины считаются по P10–P90, а не по P5–P95. Значение равно `null`, если ширина в регионе равна 0 или `n_obs` < 10.

## Сравнение с регионом

`std_diff` = (медиана вида − медиана региона) / стандартное отклонение региона. Значение равно `null`, если стандартное отклонение меньше 1e-9 или нет точек присутствия.

| abs(`std_diff`) | `direction` |
| --- | --- |
| меньше 0,25 | `same` |
| от 0,25 до 0,75 | `higher` / `lower` |
| 0,75 и больше | `much_higher` / `much_lower` |

`obs_in_region_pct` — доля точек присутствия (%), попадающих в диапазон P5–P95 региона.

## Масштаб слоёв

Проверка на реальных значениях: `scripts/check_layer_scales.py`. Диапазоны в нём — инженерная оценка, а не значения из спецификаций.

Поле `scale` равно обратной величине масштаба источника: значение слоя = (сырое значение − `diff`) / `scale`. Масштабы сверены на серверном стеке в Алматы, Астане и Актау. У этих слоёв они расходятся со спецификацией CHELSA-BIOCLIM+, потому что реальные значения ей не соответствуют:

| Слой | Спецификация | `scale` в коде | Значение при `scale` из кода (Алматы / Астана / Актау) |
| --- | --- | --- | --- |
| `rsds*` | 0,001 (соответствует `scale` 1000) | 10 | `rsdsmean`: 16,1 / 12,7 / 14,7 МДж/м²/сут |
| `sfcWind*` | 0,001 (соответствует `scale` 1000) | 100 | `sfcWindmean`: 0,92 / 2,82 / 3,34 м/с |
| `swb` | 0,1 (соответствует `scale` 10) | 1 | −40 / −408 / −872 мм, что близко к осадкам минус PET |

Значения `rsds*` и `sfcWind*` подтверждены только правдоподобием, а `swb` — ещё и сверкой с `bio12` и `petmean`.
